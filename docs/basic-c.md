# 기초 C 편집과 AI 예제

C 모드에서는 `int main(void)` 하나 안에 정수형 지역 변수·고정 크기 배열·연산·조건문·반복문을 작성한다.
전처리 지시문, 추가 함수·함수 호출, 입출력, 전역 선언, 포인터, 실수형, 동적 메모리는 지원하지 않는다.
입력은 초기값으로 지정하고 결과는 변수·배열 또는 정수 반환값으로 확인한다.
컴파일은 기존과 같이 `rv32im`, `-O0 -g`를 사용한다.

- 편집기에 지원 범위를 표시하고 기본/학습 예제도 main 내부 선언으로 통일한다.
- AI 생성 요청에 같은 범위를 포함한다. C 코드의 수동·자동 적용은
  `POST /api/v1/build/validate-c`에 `{content}`를 보내 `basic-c-v1` 정책 통과 후 실행한다.
- 정책 위반·API 오류·알 수 없는 응답은 적용을 차단하고 이유를 표시한다.
  검사 중 편집·파일 전환·모드 전환·컴파일이 발생하면 이전 코드로 덮어쓰지 않는다.
- ASM 적용은 기존 동작을 유지한다. C 컴파일 실패의 `diagnostics`는
  `{code, message, line, column}` 배열이며 빌드 결과에서 로그를 열지 않아도 표시한다.

백엔드 검증 API를 먼저 배포한다. 프론트의 요청 지침은 AI 출력 자체를 보장하지 않지만,
편집기 적용과 실제 컴파일은 동일한 백엔드 구문 검사로 제한한다.
